### 🚀 Featured Project — Restaurant Management API

A complete, production-style REST API for managing restaurants and dishes, built to show real-world backend skills — not just a toy project.

**What it does:**
- 🔹 Full CRUD operations for Restaurants & Dishes
- 🔹 Secure login and access control using JWT & ASP.NET Core Identity
- 🔹 Stores data in Azure SQL using Entity Framework Core
- 🔹 Handles errors cleanly with a global exception-handling system
- 🔹 Tested with xUnit (unit + integration tests)
- 🔹 API documentation built with Swagger, so it's easy to explore
- 🔹 Automatically builds and deploys itself using GitHub Actions (CI/CD)
- 🔹 Runs on Azure App Service, with separate Dev and Prod environments
- 🔹 Uses Azure Blob Storage for files/images and Application Insights to track performance

🔗 **Repository:** [Restaurants](https://github.com/ccesuman/Restaurants)

**How it's deployed on Azure:**

Every code push goes through GitHub Actions, which builds and deploys the app to Azure App Service. Restaurant and dish data live in Azure SQL, images go into Azure Blob Storage, and Application Insights watches over the app to catch issues early.
